2 КОРОТКИЙ ОПИС ПРОЕКТУ

2.1 Назва та призначення системи

SportManager — інформаційна система управління спортивними командами, що
автоматизує процеси обліку гравців, планування тренувань та змагань, реєстрацію
медичних даних, відвідуваності, спортивної статистики та інвентарю.

Система орієнтована на три категорії користувачів:
- Адміністратор — повний доступ до управління системою, користувачами та даними;
- Тренер — управління командою, гравцями, подіями, травмами та інвентарем;
- Гравець — перегляд особистих даних, розкладу, медичної інформації та статистики.

2.2 Архітектура системи

Система складається з чотирьох компонентів:
- Backend — REST API на Node.js 20 + Express.js, база даних PostgreSQL 15,
  JWT-автентифікація з ролевою моделлю доступу;
- Android-застосунок — Kotlin, Retrofit2 + OkHttp3, ViewModel + LiveData,
  BottomNavigationView з 6 екранами;
- Web-клієнт — React 19 + Vite, React Router DOM 7, адаптивний інтерфейс для
  адміністраторів та гравців;
- Інфраструктура — Docker + Docker Compose, Nginx як балансувальник навантаження
  (round-robin), горизонтальне масштабування до N реплік.

6 ВИСНОВКИ

У ході двох семестрів роботи розроблено повноцінну систему управління спортивними
командами SportManager, що включає серверну частину, Android-застосунок,
React-клієнт та інфраструктуру для горизонтального масштабування.

Виконані результати:
- реалізовано 15 з 18 запланованих функцій (83%);
- розроблено REST API з 13 групами маршрутів та JWT-автентифікацією;
- створено Android-застосунок на Kotlin з 6 повноцінними екранами;
- розроблено React-клієнт з адаптивним дизайном та підтримкою ролей;
- налаштовано горизонтальне масштабування через Docker + Nginx.

Три функції (IoT-інтеграція, AI-аналіз, push-сповіщення) залишаються
запланованими для майбутніх релізів системи.
